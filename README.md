# Dwelling

A 2D narrative adventure game developed in **Unity** using **C#**.

## 🎮 About the Game

Dwelling is an immersive 2D adventure game that combines exploration, storytelling, and interactive gameplay. Navigate through beautifully crafted environments, uncover mysteries, and experience an engaging narrative journey.

## ✨ Features

- **Engaging 2D Gameplay**: Immersive point-and-click exploration mechanics
- **Rich Narrative**: Compelling story with multiple interactions and dialogue options
- **Beautiful Visuals**: Pixel-perfect 2D art with custom sprite rendering
- **Save System**: Progress tracking with save and load functionality
- **Dynamic Settings**: Customizable game settings for an enhanced player experience
- **Optimized Performance**: Efficient pixel-perfect collision detection

## 🚀 Getting Started

### System Requirements

- **Unity Version**: 2021.3 LTS or higher
- **Operating System**: Windows, macOS, or Linux
- **.NET Framework**: .NET 4.x or higher
- **Minimum RAM**: 4 GB
- **Minimum Storage**: 2 GB available space
